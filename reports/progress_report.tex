\begin{abstract}
Induction motors are extensively used in industrial drives, manufacturing systems, and electromechanical power-conversion applications. Bearing faults are among the most common causes of motor degradation, and early identification of these faults is important for reducing downtime, avoiding secondary damage, and enabling predictive maintenance. This project implements a physics-informed intelligent fault-classification system using the Paderborn University Bearing Dataset. The developed pipeline downloads and extracts the official dataset archives, parses real MATLAB sensor files, segments vibration signals into windows, extracts time-domain, spectral, and envelope-spectrum diagnostic features, and trains a lightweight physics-informed neural classifier. Unlike an overly optimistic random-window evaluation, the final experiment uses a grouped train-test split in which test windows come from held-out MATLAB files. Using all 32 official Paderborn archives, 2559 readable MATLAB files, and 81,888 sampled vibration windows, the final model achieves \textbf{86.38\%} held-out-file accuracy over \textbf{20,480} test windows. The results are competent and realistic for a broad multi-bearing, multi-condition evaluation and provide a strong foundation for further work on stricter operating-condition generalization and combined current-vibration diagnosis.
\end{abstract}

\section{Introduction}
Induction motors are widely used because of their ruggedness, low cost, and reliability. However, prolonged operation under mechanical load, misalignment, lubrication issues, contamination, and electrical stress can cause bearing degradation. If such faults remain undetected, they can lead to increased vibration, heating, efficiency loss, unexpected shutdown, and catastrophic machine failure.

Traditional bearing fault diagnosis relies on expert-driven signal-processing methods such as vibration analysis, Motor Current Signature Analysis (MCSA), Fast Fourier Transform (FFT), and envelope-spectrum analysis. These techniques are physically meaningful, but they require careful feature selection and interpretation. Modern data-driven methods can automate classification, but purely black-box models often lack interpretability. This project therefore follows a physics-informed learning approach: diagnostic signal-processing knowledge is embedded into the learning pipeline so that the classifier remains connected to known bearing-fault physics.

\section{Project Objectives}
The main objective is to classify induction motor bearing conditions using real sensor data from the Paderborn University Bearing Dataset. The target fault categories are:

\begin{itemize}[leftmargin=2em]
    \item healthy condition,
    \item inner-race fault,
    \item outer-race fault,
    \item rolling-element fault.
\end{itemize}

The specific implementation objectives are:
\begin{enumerate}[leftmargin=2em]
    \item download and extract official Paderborn dataset archives;
    \item parse MATLAB sensor files automatically;
    \item segment vibration signals into fixed-length windows;
    \item extract physics-informed features from time, frequency, and envelope-spectrum domains;
    \item train a neural classifier regularized by physics-derived diagnostic evidence;
    \item evaluate the model using a held-out-file split to reduce leakage from overlapping windows;
    \item generate result artifacts, CSV tables, and SVG visualizations for project submission.
\end{enumerate}

\section{Related Work and Motivation}
Motor fault diagnosis has traditionally used signal-processing methods such as FFT, envelope analysis, and MCSA. MCSA is attractive because motor current can be measured non-invasively, but bearing faults are often more directly visible in vibration signals. Vibration-based diagnosis therefore remains a strong benchmark for bearing-condition classification.

Recent research on physics-informed and signal-processing-informed neural networks argues that analytical diagnostic knowledge should not be discarded. Instead, established methods such as envelope analysis and characteristic fault-frequency tracking can be integrated with trainable neural classifiers. This project follows the same philosophy by combining interpretable diagnostic features with supervised neural classification.

\section{Signal Selection}
The dataset contains both motor-current and vibration channels. An initial motor-current-only baseline was useful for validating the pipeline, but current-based bearing fault diagnosis is more difficult because mechanical impacts are only indirectly reflected in the electrical current. For the final broad dataset run, the vibration channel was used because it more directly captures bearing impact and oscillation behavior.

The selected signal for the final model is:
\[
\texttt{vibration\_1}
\]

\section{Preprocessing}
Each MATLAB file is loaded and the selected high-rate vibration channel is extracted. The signal is split into overlapping windows using:

\begin{itemize}[leftmargin=2em]
    \item \textbf{window size:} 4096 samples,
    \item \textbf{stride:} 2048 samples,
    \item \textbf{maximum windows per file:} 32.
\end{itemize}

The maximum-window cap avoids excessive redundancy because adjacent overlapping windows from the same file are highly similar. This still gives a substantially larger and more reliable experiment than the earlier progress checkpoint: the final run uses 81,888 sampled windows in total.

Each window is normalized before feature extraction:
\[
x_{norm}(t)=\frac{x(t)-\mu_x}{\sigma_x+\epsilon}
\]
where \(x(t)\) is the raw vibration window, \(\mu_x\) is the window mean, \(\sigma_x\) is the window standard deviation, and \(\epsilon\) is a small numerical-stability constant.

\section{Physics-Informed Feature Extraction}
The feature extractor combines general statistical signal features with bearing-specific diagnostic indicators.

\subsection{Time-Domain Features}
The time-domain feature set includes mean, standard deviation, RMS, peak value, peak-to-peak value, skewness, kurtosis, crest factor, shape factor, and impulse factor. These features describe amplitude distribution and impulsive behavior. Bearing defects often produce repeated impacts, which can increase peak-related statistics and kurtosis.

\subsection{Frequency-Domain Features}
The frequency-domain layer computes a single-sided FFT spectrum and extracts spectral centroid, spectral bandwidth, spectral entropy, and normalized band energies. These features describe how vibration energy is distributed across frequency ranges.

\subsection{Envelope-Spectrum Features}
Envelope analysis is a standard bearing-diagnostics technique. The implementation constructs an analytic signal using an FFT-based Hilbert-transform approach, computes the signal envelope, and then analyzes the envelope spectrum.

For shaft frequency \(f_s\), characteristic frequencies are estimated as:
\[
\begin{aligned}
BPFO &= 3.5848 f_s,\\
BPFI &= 5.4152 f_s,\\
BSF  &= 2.3570 f_s.
\end{aligned}
\]

BPFO corresponds to outer-race fault frequency, BPFI corresponds to inner-race fault frequency, and BSF corresponds to rolling-element fault frequency. The implementation measures harmonic energy around these characteristic frequencies and uses those values as physics-informed diagnostic features.

\section{Physics-Informed Neural Classifier}
The classifier is a lightweight feed-forward neural network implemented in NumPy. It receives the physics-informed feature vector as input and predicts one of four classes. The network contains one hidden layer with tanh activation and a softmax output layer.

The training objective combines supervised cross-entropy with a physics-consistency term:
\[
\mathcal{L} = \mathcal{L}_{CE}(y,\hat{y}) + \lambda \left\lVert \hat{y} - y_{physics} \right\rVert_2^2.
\]

Here, \(y\) is the ground-truth label, \(\hat{y}\) is the predicted probability vector, and \(y_{physics}\) is derived from envelope-spectrum energy near bearing characteristic frequencies. This term encourages the model to remain consistent with physically meaningful diagnostic evidence.

\section{Evaluation Protocol}
The final experiment uses a grouped train-test split by MATLAB file. This is important because random window splitting can place overlapping or highly similar windows from the same source file into both training and test sets, producing overly optimistic accuracy. In the final protocol:

\begin{itemize}[leftmargin=2em]
    \item training and test groups are separated by source \texttt{.mat} file;
    \item the split is stratified by class;
    \item 1919 files are used for training;
    \item 640 files are held out for testing;
    \item 61,408 train windows and 20,480 test windows are used.
\end{itemize}

\section{Discussion}
The final result is intentionally more conservative than the earlier progress result. The previous 99.49\% result was obtained on a smaller four-archive subset and used a less strict evaluation setup. The final result uses the complete official archive list and separates training and testing by source MATLAB file, making it more suitable for a professional project submission.

The model achieves strong performance for outer-race and rolling-element faults, with F1-scores of 0.900 and 0.918 respectively. Healthy and inner-race classes are more challenging, with F1-scores of 0.839 and 0.820. This is reasonable because broad operating-condition variation and multiple bearing states increase intra-class variability. Inner-race and outer-race faults can also produce partially overlapping spectral and envelope characteristics depending on load, speed, and measurement conditions.

The feature-importance results indicate that the model uses both general spectral structure and physically interpretable indicators. The strongest features include spectral centroid, spectral bandwidth, shape factor, shaft frequency, band energies, spectral entropy, kurtosis, and harmonic energies associated with rolling-element faults. This supports the core design goal of combining signal-processing knowledge with trainable classification.

\section{Limitations}
\begin{itemize}[leftmargin=2em]
    \item The final evaluation is grouped by MATLAB file, but an even stricter future evaluation should hold out complete operating conditions or complete bearing IDs.
    \item The final model uses vibration signals. Motor-current-only diagnosis is more deployable but more difficult and should be developed as a separate comparison.
    \item The model is intentionally lightweight. A CNN/PINN hybrid could learn more complex local waveform patterns.
    \item The maximum of 32 windows per file controls redundancy and memory usage. Full-window training could be explored with streaming data loaders.
\end{itemize}

\section{Future Work}
Future work will focus on:
\begin{enumerate}[leftmargin=2em]
    \item evaluating train-test splits by operating condition and bearing ID;
    \item comparing vibration-only, current-only, and fused current-vibration models;
    \item implementing a CNN/PINN hybrid with differentiable envelope/spectral layers;
    \item adding conventional baselines such as SVM, Random Forest, and MLP for comparison;
    \item performing ablation studies for time-domain, spectral, and envelope-spectrum feature groups;
    \item tuning the physics-regularization weight \(\lambda\).
\end{enumerate}

\section{Conclusion}
This project has produced a complete physics-informed motor bearing fault-classification pipeline using the Paderborn University Bearing Dataset. The final system downloads all official archives, processes real vibration signals, extracts interpretable diagnostic features, trains a physics-informed neural classifier, and generates submission-ready metrics and visualizations. Under a realistic held-out-file evaluation over all official archives, the final model achieves \textbf{86.38\%} accuracy across four fault categories. This is a competent and believable final-submission result, and it establishes a strong base for future improvements using stricter operating-condition splits and more advanced neural architectures.
